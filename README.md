# Employee Attrition & Wellbeing EDA

**Análisis de satisfacción, bienestar y rotación del personal**\
*Proyecto de Data Analytics / People Analytics*

## Descripción

Este proyecto realiza un **Análisis Exploratorio de Datos (EDA)**
utilizando el dataset **IBM HR Analytics** con el objetivo de
identificar los factores que influyen en la satisfacción, el bienestar y
la rotación del personal.\
A partir de datos de RRHH, se generan insights que ayudan a comprender
por qué las personas permanecen o abandonan la organización.

## Objetivos del proyecto

-   Analizar los principales factores asociados a la rotación
    (Attrition).\
-   Estudiar el impacto de la satisfacción laboral, cultura
    organizacional, horas extra y engagement.\
-   Crear variables proxy para medir conceptos cualitativos
    (BurnoutRisk, CulturaPositiva, Engagement).\
-   Validar hipótesis relacionadas con bienestar y retención del
    talento.

## Dataset

-   **Nombre:** IBM HR Analytics -- Employee Attrition & Salaries\
-   **Tamaño:** 1.470 filas · 35 columnas\
-   **Contenido:** datos demográficos, laborales, de satisfacción y de
    percepciones del personal.

## Principales hallazgos

-   Las **horas extra** aumentan la probabilidad de renuncia (30% vs
    10%).\
-   El **burnout** duplica las tasas de abandono.\
-   La **cultura organizacional positiva** reduce la rotación.\
-   El **engagement** es un fuerte predictor de permanencia.\
-   La mayor rotación ocurre en empleados con **0--2 años** de
    antigüedad.\
-   Las oportunidades de desarrollo pueden incrementar movilidad externa
    si no hay crecimiento interno real.
